7. CLEAN UP GLOBAL CSS

Keep only:
- Tailwind import
- Root variables
- Font defaults that cannot live in the layout
- Global reset rules
- Reusable keyframes or rules that Tailwind cannot express cleanly

Delete only CSS selectors that have already been replaced and verified.

Then run:

npm run lint
npx tsc --noEmit
npm run build
git diff --check
git add -A
git commit -m "Remove obsolete global CSS"


8. FINAL VERIFICATION

Test these routes at desktop and mobile widths:

- http://localhost:3000/gallery
- http://localhost:3000/the-artist

Final commands:

npm run lint
npx tsc --noEmit
npm run build
git status --short


9. PUSH THE MIGRATION BRANCH

git push -u origin refactor/tailwind-migration


IMPORTANT RULES

- Do not migrate every page in one edit.
- Do not remove a CSS rule until the related component is visually verified.
- Preserve the current MVVM structure.
- Keep data in view models and presentation in view components.
- Preserve all desktop and mobile reference layouts.
- Use the current main branch commit as the rollback point.
